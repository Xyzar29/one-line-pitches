One sentence, 230 characters, that would convince a friend who has never coded to let an AI agent build their first app idea on make.fun. It is the whole entry: no code, no explanation — `main.ts` just writes the pitch to `entry.txt`.

> That app idea you keep talking about — describe it in plain words to an AI agent on make.fun and it will build you a real first version to try, no coding needed, so tonight your idea finally becomes something you can actually use.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
cat /tmp/out/entry.txt
```
